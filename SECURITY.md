# Security policy

## Reporting a vulnerability

Report a vulnerability through GitHub's private vulnerability reporting:
<https://github.com/bgoleno/fabrikito/security/advisories/new>.

Do not report a vulnerability as a public issue or pull request, and do not describe it in a public
place. Include what you found, how to reproduce it, and which version or commit you ran.

## Scope

fabrikito starts Claude Code sessions on your machine. The permission rules it writes guard
against accidents, not a determined user or seat: see [Safety](README.md#safety) for what they cover and
what they do not.
